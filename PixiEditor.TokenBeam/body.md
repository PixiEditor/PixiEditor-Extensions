## What is it?

[Token Beam](https://tokenbeam.dev/) is an open-source protocol for synchronizing colors and palettes in real time between two apps.

This extension is **receive** only, which means it can only receive palettes. 

## How to use it?

1. Open Edit -> Token Beam Settings
2. Paste your token into Token field (and set server field, if needed) and click "Connect".
3. Once PixiEditor receives palette, it will set it as an active palette for your **active document**
